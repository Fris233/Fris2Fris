# Fris2Fris

A prebuilt version for windows is in the releases section (a zip folder containing both client.exe and server.exe and batch script that runs the base case)

Steps to run:
  1- Install rust (make sure by running 'cargo --version' in your terminal)
  2- Clone the project github (or download zip file)
  3- Go to Fris2Fris folder which contains cargo.toml
  4- Open terminal from that folder and run:
      cargo build --release --bin server
      cargo build --release --bin client

  5- You will now have executable files in your target/release/ folder for both server and client.
  6- run the server and at least 4 clients.
  7- Watch the chunks fly!
